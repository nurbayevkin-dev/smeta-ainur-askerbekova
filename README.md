# Смета за 5 минут

Простое веб-приложение: добавляешь позиции (название, количество, цена) и сразу видишь итоговую сумму сметы.

## Файлы
- index.html — структура страницы
- styles.css — оформление
- script.js — расчёты и кнопки

## Как открыть
Дважды кликнуть на index.html — откроется в браузере. Установка не нужна.
