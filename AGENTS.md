# Правила для агента

- Работать только в этой папке, другие папки не трогать.
- Не ломать готовое: сохранять существующие разделы и работающие функции.
- Без npm, пакетов и сборки — только чистые HTML, CSS и JavaScript.
- Данные не отправлять: никаких серверов, API и аналитики, всё остаётся на устройстве.
- Удобно с телефона: страница должна хорошо работать на маленьком экране.
- После каждой правки перечислять, что изменено, и честно писать, что проверено.
